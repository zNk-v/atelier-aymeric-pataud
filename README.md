# Atelier de cadrage stratégique — Aymeric Pataud

Livrable de l'atelier de cadrage vendu 690 €, réalisé en août 2026.

**Document privé.** Non indexé (`noindex` + `robots.txt` bloquant tous les robots, y compris ceux des moteurs IA). L'URL n'est référencée nulle part.

## Contenu

Site statique d'une page, structuré en neuf sections navigables :

1. En bref — les trois chiffres qui résument le diagnostic
2. Vos clients — quatre profils, matrice de priorisation
3. Les requêtes — 60 mots-clés testés avec volumes réels (Semrush, base France)
4. Qui capte — analyse des pages de résultats et du paysage concurrentiel
5. Votre visibilité — Google, moteurs IA, LinkedIn
6. Le site — arborescence
7. Le plan — éditorial 6 mois
8. Les messages — page par page
9. La suite — questions bloquantes et limites de l'étude

## Technique

HTML/CSS autonome, sans dépendance ni framework. Une seule ressource externe : Google Fonts (Fraunces, Inter).

Déployé via GitHub Pages depuis la branche `main`.

## Périmètre

Ce dépôt est **indépendant du site d'Aymeric Pataud** (`zNk-v/aymeric-pataud`). Aucun code, aucun contenu, aucun déploiement partagé.
